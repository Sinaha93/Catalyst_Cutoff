# Catalyst_Cutoff

Windows PC에서 혼자 사용하는 촉매 마감 자동화 프로그램의 설계 저장소입니다. ERP·희성·유미코아 자료를 대조하고, 제품별 물류 흐름과 BOM을 이용해 마감 수량을 검토한 뒤 엑셀을 생성합니다. **프로그램 구현은 아직 시작하지 않았습니다.**

## 먼저 읽을 문서

1. [2026-10-12 전체 점검·운영 설계](docs/reviews/2026-10-12-전체점검-운영설계.md): 현재 확보/검증/미완료 상태, 엑셀과 프로그램의 관리 역할, 통합 구조와 개발 순서의 기준입니다.
2. [촉매 마감 자동화 상세 설계](docs/superpowers/specs/2026-10-08-촉매마감-자동화-design.md): 사용자 확인 규칙, 예외, 원본 위치와 계산 설계입니다.
3. [2026-10-08 검토 기록](docs/reviews/2026-10-08-검토폴더-검토결과.md): 당시 자료 상태를 기록한 이력입니다. BOM 미수령 등 당시 내용을 현재 상태로 해석하지 않습니다.

## 현재 진행 단계 — 2026-10-13

**구현 전 상세 설계를 진행 중입니다.** 경로표의 마감처 정리는 전체 설계 완료를 뜻하지 않습니다. 현재 통합 경로표는 108품번·123경로이며 단산 이력과 기존 유보 경로를 포함합니다. 최근 공장 정정, M/H-08010 구분, 28991-4C520 전주 직사급 예외를 반영했습니다.

설계는 경로별 수불 항목 연결, 마감 계산 순서, 월별 입력·검토 화면, 결과 저장·출력의 네 가지를 다룹니다. 운영 설계 13절의 전체 초안을 14~17절에서 구체화했습니다. **월별 화면 시안과 이력 저장·수정·재확정 설계안을 작성하고, 출력 견본 대조를 9월 확정 명세 전체로 확대했습니다.** 전체 확정값 대조와 원본부터 배분 계산을 재현하는 검증은 구분합니다. 사용자 검토, 공유 촉매의 전체 총량 구분과 2JAV0 당시 자료 차이는 남아 있습니다.

추가한 `HkmgMmin020 (5).xlsx`는 매월 받을 **글로비스 실제 입고 검토 자료**입니다. 제품 입고→BOM→직사급 예외를 대조한 9월 글로비스 촉매 18,538개가 최종 마감과 품목별로 일치합니다. 희성 가공본에 있었던 2JAN0 71개는 실제 입고 원본에 없고 최종 미정산으로 확인됐습니다. 신규 원본·최종 마감·미정산 대조 결과인 **운영 설계 15절이 이전 가공본 비교보다 우선**합니다. 원본과 과거 마감은 수정하지 않았으며 자료 가져오기 기능도 아직 구현하지 않았습니다.

이력 설계는 작업 초안 자동 저장과 확정본을 구분합니다. 확정 당시 원본·BOM·경로·단가·계산 버전·월별 입력·최종 명세·미정산을 함께 남기고, 수정은 기존 확정본을 보존한 채 새 차수로 재확정합니다. 전월 재확정의 다음 달 이월 영향은 표시하되 자동 덮어쓰지 않습니다. 재출력은 저장된 확정값을 사용합니다. 백업·자료 복구·프로그램 업데이트 시 보존 조건까지 운영 설계 17절에 정리했으며, 저장 기능 자체는 아직 구현하지 않았습니다.

## 최초 점검 기록 — 2026-10-12

아래 수치와 미확인 목록은 최초 점검 당시의 기록입니다. 이후 추가 자료·사용자 답변은 운영 설계 12~13절 및 최신 통합 경로표를 우선합니다.

- 업무 엑셀 11개를 점검했습니다. BOM과 2026년 9월~2027년 1월 촉매 소요량 파일을 받았습니다. 원본 포캐스트는 별도로 제공되지 않았습니다.
- BOM은 160행·제품/반제품 148품번·촉매 131품번입니다. 대상 H28950-/H289G0- 반제품 수불 19행은 모두 연결됩니다.
- 9월 실제 마감 151,090개·19,870,764,335원, 미정산 20,874개는 ERP 및 명세와 맞습니다. 원본부터 자동 배분하는 프로그램을 검증했다는 의미는 아닙니다.
- 현재 보고서의 `종합3(누적)`은 2026년 8월까지만 있습니다. 과거 표 간 차이와 기존/신규 계획의 버전 차이도 있어 이관 검토가 필요합니다.
- 기존 창고 연결표는 70행 중 확인완료 13행·확인필요 57행인 초안입니다. 물류 경로·집계 지점·현대기아 세부 공장·ERP 통합 마감처를 표현하도록 관리 구조를 확장해야 합니다.
- 같은 제품/촉매의 다중 납품처는 제품 수량 비율로 촉매 마감 대상 총량을 배분합니다. 글로비스는 실제 제품 입고처리 기준이며, 경유 후 기록은 중복 합산하지 않습니다.
- 세종의 울산 경로는 현대기아 울산3, 영천의 울산 경로는 품번별 울산1/5입니다. ERP는 현대 울산으로 합산합니다. 영천의 개별 품번 매핑은 아직 필요합니다.
- 완성차 직납 및 서열-전주(HSL) 상세는 사용자의 후속 설명을 기다리는 보류 항목입니다. UI 개선은 설계에 반영했으며 시안 검토 후 구현합니다.

## 관리 구조 및 다음 작업

운영 제안은 **원본 수령 엑셀·BOM·계획은 가져오고, 프로그램에서 경로·배분·단가 예외·월별 조정·확정 이력을 관리하며, 하나의 확정 데이터로 엑셀을 생성**하는 방식입니다. 동일 내용을 엑셀과 프로그램 양쪽에서 독립 수정하지 않습니다.

희성·현대기아 세부공장·ERP·미정산의 대표 출력 견본을 작성하고 같은 과거 확정 명세로 대조했습니다(운영 설계 18절). 이 과정에서 **글로비스 미입고 449개 외 전월 잔여 1개가 있어 전체 미정산은 450개**임을 확인해 이전 설명을 정정했습니다. 원본 미정산 31~35행이 근거이며 실제 마감 18,538개는 변하지 않습니다.

9월 전체 대조는 확정 명세 114행·미정산 61행·희성 84행·유미코아 69행을 포함합니다(운영 설계 19절). 품번×ERP 마감처 144건의 수량 잔액 차이는 모두 0입니다. 촉매사 원문 마감과 실제 마감이 다른 12품목 중 9품목은 기존 미입고·확정 미처리 이력으로 연결했습니다. 나머지 희성 3품목의 각 2개 입고 차이는 전표·시점을 확인하지 못해 별도로 보존했습니다. 현재 BOM에 없는 모비스 마감 21품목도 과거 확정 이력에는 포함했습니다.

9월 확정 마감의 97촉매 전체에 제품 수불·BOM 근거를 연결해 배분 검토 상태를 분류했습니다(운영 설계 20절). 사용자가 **기본은 비율 계산이며 일부 품목은 그달 예외가 있다**고 확인했습니다. 기본 계산값을 유지하면서 월별 최종 수량·사유를 수정하고 합계를 검토하는 견본을 작성했습니다. 과거 비율과 다른 8촉매를 오류나 확정된 예외로 자동 분류하지 않으며, 과거 전 건 자동 재현을 다음 단계의 필수 조건으로 삼지 않습니다.

UI와 출력 양식은 모두 검토 초안입니다. 공유 촉매 총량의 독립 산정, 누락·유보된 배분 근거 보완, 현대기아 실제 등록 형식 확인과 기존 화면의 잔액 정정 반영은 남아 있습니다. 미확인 항목은 Codex가 자료로 해결할 내용과 사용자의 월별 입력·업무 판단이 필요한 내용을 구분합니다. 필요한 판단만 구체적으로 질문하며 미확인 항목을 묵시적으로 승인된 것으로 처리하지 않습니다. 네 가지 설계가 정리되기 전에 구현 단계로 넘어가지 않습니다.

운영 설계 21절에서 **원천 수량 대조 → 해당 월 보류·해소 → 글로비스·직사급 → 일반 배분 → 월별 수정 → 확정 검산**의 총량 계산 순서를 정리했습니다. 촉매사 목록과 전주 직사급을 포함한 154촉매 중 원천 합계 일치 131·차이 22·Summary 미수록 1로 구분했습니다. 이월·당월 구성이 다른 자료를 섞어 중복 계산하거나 발주를 실제 납품으로 간주하지 않습니다. 미정산 20,874개를 사유별로 연결했으며, 과거 미정산을 차감한 검산과 새 달의 독립 산출을 구분합니다. 후속 작업은 이 계산 순서를 월 작업의 필수 입력·예외 검토·확정 조건에 연결하는 것입니다.

운영 설계 **22절에서 월 작업 규격까지 연결했습니다.** 등록된 기준과 전월 확정본을 재사용하고, 사용자 입력은 필요한 제품 분할·월별 촉매 수정·자료만으로 정해지지 않는 보류/해소 처리로 구분합니다. 사유가 확인된 미정산이나 과거 비율 차이만으로 월 확정을 막지 않으며, 새 월의 필수 자료·귀속·입력 누락과 재계산 필요 상태는 해결해야 합니다. 다음 단계는 **1차 구현 범위·보류 기능·검증 순서 정리**입니다. 실제 프로그램과 기존 화면 시안은 이번 단계에서 변경하지 않았습니다.

## 자료 위치와 재개 안내

```text
작업 폴더/
  Catalyst_Cutoff/                 설계·구현 저장소
  BOM, 월계획 파일/                BOM 및 가공 소요량 2개
  촉매마감_작업이관_20261008/
    검토/                         ERP·수불·촉매사·보고서·연결표 8개
    원본/                         희성 출하 원본 1개
```

현재 작업 폴더는 `D:/Documents/Codex/촉매 마감`입니다. 다른 PC에서는 실제 자료를 별도로 옮기고 경로 대신 자료 역할로 등록합니다. 저장소에는 업무 엑셀, 분석 중간 파일, API 키를 포함하지 않습니다.

기존 확인 사항은 다시 질문하지 않습니다. 사용자 수정 실수를 새로운 반복 업무 규칙으로 만들지 않습니다. 답변은 한국어 존댓말로 진행합니다. 결과물은 엑셀까지이며 PPT 생성은 범위에 포함하지 않습니다.
