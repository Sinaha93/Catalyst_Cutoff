# Catalyst_Cutoff

Windows PC에서 혼자 사용하는 촉매 마감 자동화 프로그램입니다. ERP와 촉매사 자료를 대조하고 제품 납품·BOM·마감처를 연결하여 마감 수량과 금액을 검토한 뒤 엑셀을 만드는 것이 목표입니다.

## 현재 상태 — W5 통합 마감 검토

- 월 작업, 메모, 원본 보관, 자료 검산·정정·채택 및 변경 이력
- 희성 출하·적송재고, ERP 입고·제품/반제품 수불, 유미코아 Summary, 글로비스 실제 입고 읽기
- BOM·경로 연결, ERP 단가·월별 적용 단가·월계획 검토
- 희성 마감 수량 배분, 공장별 수량 보완, 원천 수량 자동 대조
- 월별 보류·해소 저장, 이력 조회, 기준 변경 감지 및 희성 배분 연결

- 원천 구성 선택, PDF 원값을 보존하는 이월 수정, 월별 제품 수량 구분·상세 공장 수량·단가 수정
- 유미코아 전월 적송 PDF, Summary 원문 마감과 보류 처리 결과 대조
- 현재 BOM 밖의 실적 포함 전체 검토, ERP 모비스 단일 마감의 근거 연결, 조건을 만족하는 보류 없음 일괄 확인
- 월 확정본 잠금·재작업·새 확정 버전, 전월 확정본 지정 연결, 보류분 단가 및 해소 내역 보존
- 동일 확정본의 희성 원본/가공·유미코아·ERP 거래처·미정산·검산·수정 이력 엑셀, 원본 포함 검증 백업
- 프로그램 경로·공장·ERP 마감처 및 단가 예외 관리, BOM 변경 비교, 기간별 기준 버전과 월별 적용
- 월 작업 초기화: 이전 초안 보관, 원본·기준·과거 확정본 보존
- 사용 가이드: 작업 순서, 자료 구분, 미마감 조정 예시와 합성 자료 화면 이미지
- 월 작업 삭제: 확인 후 해당 월 작업과 전용 보관 파일을 삭제하며, 다른 월의 이월 참조가 있으면 차단
- Windows 창 없는 실행 진입점: `pythonw -m backend.desktop_launcher`. 설치·빌드가 끝난 소스 환경에서 사용하며 실행 오류는 안내창과 로컬 로그로 확인

통합 마감 검토 화면에서 원본과 수정 이력을 확인한 뒤 확정합니다. 실제 자료의 미확인 판단을 자동 승인하지 않습니다. UI는 1920×1080을 기준으로 상단 메뉴, 왼쪽 품목, 오른쪽 근거·수정을 연결했으며 최종 디자인은 미확정입니다. 상세 규칙은 [월 통합 검토 운영 안내](docs/operations/monthly-closing.md)에 있습니다.

W4.3 이관 검토 후 상세 공장별 배분을 먼저 계산하고 ERP 지역 합계를 별도로 표시하도록 수정했습니다. 미확인 경로는 연결된 촉매의 계산을 막으며, 엑셀 총량도 촉매사·ERP·장부 원천과 대조합니다. 관련 품목의 근거가 바뀐 입력만 재확인 대상으로 구분합니다. 이전 배분입력 양식은 새 양식으로 다시 확인해야 합니다.

## 다른 PC에서 시작

Windows에 Python 3.12와 Node.js 22.12 이상을 준비합니다. 코드와 업무 자료는 별도로 옮깁니다.

```powershell
git clone https://github.com/Sinaha93/Catalyst_Cutoff.git
cd Catalyst_Cutoff
.\setup.ps1
.\start.ps1 -ChooseDataDir
```

자료 폴더 선택 창에서 별도로 옮긴 `프로그램_개발검토_W4_3` 폴더를 선택합니다. 기존 DB는 스키마 변경 전에 백업합니다. 의존성 설치에는 인터넷이 필요하며 현재 구현 기능은 외부 AI API 없이 실행됩니다.

이관 ZIP의 코드 폴더에는 미커밋 변경이 있습니다. 그 위에서 바로 pull하거나 덮어쓰지 말고, 새 폴더에 clone한 코드로 ZIP의 업무 자료 폴더를 여세요. ZIP 작성 당시의 미푸시 안내보다 이번 GitHub 코드 안내를 우선합니다.

상세한 재개 순서는 [개발 재개 안내](docs/handoff/README.md)를 확인합니다. 업무 원본·ZIP·DB·검증 화면과 실제 업무 수치를 담은 이번 검토 문서는 이번 커밋에 포함하지 않습니다.

## 검증

```powershell
.\.venv\Scripts\python.exe -m pytest -q
cd frontend
npm.cmd run build
npm.cmd run test:browser
node tests/holds.mjs
node tests/closing.mjs
node tests/masters.mjs
```

브라우저 검증에는 Microsoft Edge가 필요합니다. 검증은 가상 자료와 별도의 실제 자료 복사본으로 수행합니다. 업무 원본·실제 DB·생성된 출력과 화면 캡처는 Git에서 제외합니다.

프로그램 기준 관리(경로·공장·ERP 마감처, BOM 버전, 기간별 단가 예외)와 월 작업 초기화는 [운영 안내](docs/operations/master-management.md)를 확인합니다. 초기화는 기존 초안을 보관하고 새 초안을 만드는 기능이며 원본·기준·확정 이력은 유지합니다.

GitHub 전송은 사용자가 해당 시점에 명시적으로 요청한 경우에만 진행합니다. 결과물 범위는 엑셀이며 PPT 생성은 포함하지 않습니다.
