# Catalyst_Cutoff

Windows PC에서 사용하는 촉매 마감 자동화 프로그램의 설계 저장소입니다. ERP 입고와 희성촉매·유미코아 자료를 대조하고 엑셀 마감 보고서를 생성하는 것을 목표로 합니다.

## 설계 문서

[촉매 마감 자동화 설계](docs/superpowers/specs/2026-10-08-촉매마감-자동화-design.md)

문서에는 자료 분리, 품목·마감처·단가 관리, 마감·미정산 계산, OpenRouter 양식 해석과 비용 관리, 구현 순서가 기록되어 있습니다.

## 이어서 할 작업

프로그램 구현은 아직 시작하지 않았습니다. 설계 문서의 **11장**부터 확인해 주세요.

현재 우선 과제는 **희성촉매 마감 파일을 작성하는 실제 순서를 파악하고 작성 과정을 쉽게 만드는 범위를 정하는 것**입니다. 이후 전체 프로그램은 품목 관리표 → 파일 읽기 → 계산·검증 → 엑셀 출력 → OpenRouter 및 사용 화면 순서로 개발합니다.

월계획 파일의 실제 양식은 아직 확인 전입니다. 결과물은 엑셀까지이며 PPT 생성은 범위에 포함하지 않습니다.

실제 업무 엑셀·PPT와 API 키는 이번 업로드에 포함하지 않았습니다. 다른 컴퓨터에서 파일 분석을 이어가려면 실제 자료를 별도로 준비해야 합니다.
