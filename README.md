# Catalyst_Cutoff

Windows PC에서 사용하는 촉매 마감 자동화 프로그램의 설계 저장소입니다. ERP 입고와 희성촉매·유미코아 자료를 대조하고 엑셀 마감 보고서를 생성하는 것을 목표로 합니다.

## 설계 문서

[촉매 마감 자동화 설계](docs/superpowers/specs/2026-10-08-촉매마감-자동화-design.md)

문서에는 자료 분리, 품목·마감처·단가 관리, 마감·미정산 계산, OpenRouter 양식 해석과 비용 관리, 구현 순서가 기록되어 있습니다.

[검토 폴더 전체 검토 결과](docs/reviews/2026-10-08-검토폴더-검토결과.md)에는 입력 7개 파일의 역할, 현재 결과물과 ERP 대조, 추가 준비 자료 및 자동화 시 이관 주의 사항을 기록했습니다. 설계 문서 14장에도 반영했습니다.

## 이어서 할 작업

프로그램 구현은 아직 시작하지 않았습니다. 설계 문서의 **11장**부터 확인해 주세요.

현재 우선 과제는 **희성촉매 마감 파일을 작성하는 실제 순서를 파악하고 작성 과정을 쉽게 만드는 범위를 정하는 것**입니다. 이후 전체 프로그램은 품목 관리표 → 파일 읽기 → 계산·검증 → 엑셀 출력 → OpenRouter 및 사용 화면 순서로 개발합니다.

월계획 파일의 실제 양식은 아직 확인 전입니다. 결과물은 엑셀까지이며 PPT 생성은 범위에 포함하지 않습니다.

실제 업무 엑셀·PPT와 API 키는 이번 업로드에 포함하지 않았습니다. 다른 컴퓨터에서 파일 분석을 이어가려면 실제 자료를 별도로 준비해야 합니다.

## 다른 컴퓨터에서 재개하기

1. 이 저장소를 clone하거나 기존 checkout에서 로컬 변경을 확인한 뒤 최신 문서를 가져옵니다.
2. 별도로 옮긴 `촉매마감_작업이관_20261008.zip`을 작업 폴더에 풉니다. ZIP 자체와 업무 엑셀은 GitHub에 올리지 않습니다.
3. 압축을 풀면 `검토`에 기존 자료 7개와 `창고_촉매마감처_연결표.xlsx`가 있고, `원본`에 희성 출하 원본이 있습니다. 마감 보고서는 미정산 두 품목의 중복 수정이 적용된 파일입니다.
4. 설계 문서 11·14장과 전체 검토 결과를 읽고 이어갑니다. 프로그램 구현은 아직 시작하지 않았고, BOM과 월계획은 추후 받을 예정입니다.

연결표는 ERP 자료구분·창고명·제품/반제품 품번 조건·경유처·촉매 마감처·수량 기준·확인상태·비고의 8개 열입니다. 확인된 경로 3개와 미확인 창고 23개 행을 넣었습니다. 노란 칸을 입력하고 확인상태를 바꿉니다. 품번 공란은 창고 전체, 끝의 `*`는 품번 시작문자 조건이며 정확한 품번 → 시작문자 → 창고 전체 순서로 적용합니다. 동일 우선순위 규칙이 겹치거나 확인필요인 행은 자동 배분에 사용하지 않습니다. 이 규칙 적용 기능은 향후 구현할 설계이며 엑셀만으로 실행되는 기능은 아닙니다.

세종공업(화성)의 M28950-2JAV0는 현대 울산·당월 입고 이동처리, 원자재(창고+라인)의 당진 대상 H28950-/H289G0- 반제품은 기아 화성·출고 적송처리로 채웠습니다. 반제품의 잘못 기록된 출고 이동처리는 확인 후 포함하며 이후 완제품 흐름과 중복 합산하지 않습니다. 촉매와 제품을 연결하려면 추후 BOM이 필요합니다.

다음 작업자는 현재 수기 실수의 중복을 새 업무 규칙으로 취급하거나 이미 확정한 미마감 여부를 다시 질문하지 않습니다. 필요한 확인은 한 번에 한 건씩 한국어 존댓말로 진행합니다.
