# 기준 관리와 월 작업 초기화

## 화면 구분

- 자료 등록: 촉매사 출하·적송재고, ERP 촉매 입고, 제품·반제품 수불, 글로비스 실제 입고, 월계획과 추가 비교 자료
- 기준 관리: BOM, 촉매 기본 단가, 물류 경로·공장. 파일 등록부터 검산·비교·버전 저장·적용까지 이 화면에서 처리
- 마감 검토: 이번 달 미마감·수량·가단가·마감처별 예외 수정

월계획은 매월 바뀌므로 자료 등록의 별도 ‘월계획’에서 등록·채택합니다. BOM·단가·경로의 기준 파일과 등록 이력은 자료 등록에 표시하지 않습니다.

## 기준 파일 등록과 변경

1. 기준 관리 상단의 **BOM·촉매 단가·경로·공장 상태 카드**를 확인하고 관리할 카드를 선택합니다.
2. 같은 화면의 **기준 파일**에서 XLSX를 선택하고 **기준 파일 읽기**를 누릅니다.
3. 읽기 결과를 확인합니다. 정상 파일은 아래 **등록한 엑셀 후보**에 자동 선택됩니다. 오류가 있으면 원본을 확인하고 수정본을 다시 읽습니다.
4. 적용 시작월·필요한 종료월과 변경 사유를 입력하고 **기준 변경 내용 비교 → 새 기준 버전 저장**을 진행합니다.
5. **이번 달 적용 전 차이 보기 → 이 버전을 이번 달에 적용**으로 반영합니다.

파일 읽기만으로 기존 기준을 교체하지 않습니다. 등록한 기준 파일 목록에서 과거 후보의 읽기 결과를 확인하고 원본을 내려받을 수 있습니다. 파일명으로 자료 종류나 적용 기간을 추정하지 않습니다.

경로와 촉매 기본 단가는 저장된 버전을 불러와 화면에서도 수정할 수 있습니다. BOM 구성은 기존 엑셀 수정본으로 등록합니다. 같은 제품에 여러 물류 경로를 둘 수 있으며, 새 버전에서 행을 제외해도 이전 버전은 보존됩니다.

경로의 **배분에 집계**를 해제하면 이동 추적용입니다. 중간 납품과 후속 이동을 중복 합산하지 않습니다. 같은 원본이 여러 공장에 연결되면 공장별 수량 구분을 확인합니다. 글로비스는 실제 입고 자료를 사용하며 일반 비율로 대체하지 않습니다.

## 기본 단가와 이번 달 가단가

촉매 단가 기준은 품번별 기본 단가입니다. 기존 파일로 채택한 단가도 조회·수정할 수 있습니다. 서로 다른 단가 후보를 임의로 하나로 합치지 않습니다.

이번 달에만 사용할 가단가·마감처별 예외는 **마감 검토 → 촉매 선택 → 단가**에서 정단가/가단가, 적용값, 사유·근거를 저장합니다. 예외 단가 파일 등록은 제공하지 않습니다. 과거 예외 기준 데이터는 호환 계산·이력용으로 보존합니다.

## 적용 기간과 과거 확정본

새 월을 열면 그 달에 유효한 기준을 연결합니다. 이미 열어 둔 월은 새 버전을 저장해도 자동 교체하지 않으며 명시적으로 적용합니다. 과거 확정본은 당시 수량·단가·BOM·경로를 보존합니다. 기준 변경으로 영향을 받는 월별 판단은 재확인합니다.

## 월 작업 초기화

월 작업의 **월 작업 초기화 → 이 월의 입력 다시 시작 → 사유 입력 → 이전 초안을 보관하고 초기화**를 사용합니다.

메모·월별 이월 수정·원천 선택·미마감·수량·단가 수정·월별 경로·공장별 분할 입력을 초기화합니다. 월계획과 엑셀 배분 입력은 이번 달 사용만 해제합니다.

BOM·경로·촉매 기본 단가·기존 단가 기준, 다른 원본의 채택, 전월 확정 이월 연결, 원본 파일·이력·과거 확정본은 보존합니다. 확정 월은 먼저 새 확정 버전 작업을 시작해야 합니다. 초기화와 월 작업 완전 삭제는 별도 기능입니다.


## 기준 상태 카드

‘이번 달 사용’은 해당 월에 적용한 버전 또는 채택한 기존 파일 기준입니다. 읽기만 완료된 파일, 저장했지만 미적용인 버전, 등록 전 상태를 구분합니다. 기존 버전을 사용하면서 새 버전이 저장된 경우 현재 사용 표시와 새 버전 적용 대기를 함께 표시합니다. 상태 조회에 실패하거나 최신 수정 순서와 다른 결과는 사용 완료로 표시하지 않습니다. 카드 클릭으로 관리 대상을 선택하며 중복 선택창은 제공하지 않습니다. 이 상태는 등록·적용 확인이며 제품별 BOM 연결·수량의 업무 검산 완료를 뜻하지 않습니다.


## 선택한 기준 자료 초기화

기준 카드 선택 → 화면 하단 **선택한 기준 자료 초기화** → **초기화 범위 확인** 순서입니다. 선택한 종류의 이 자료 폴더 전체 등록 버전·후보 파일 개수를 확인합니다. 확인 체크 후 **확인한 기준 초기화 실행**을 누르면 해당 종류의 등록 버전·파일·적용 연결을 비우고 다시 등록할 수 있습니다. 원본이 다른 자료와 공유되면 파일은 보존합니다. 다른 기준, 월계획, 월 실적과 월별 판단은 지우지 않습니다. 프로그램 안에서 되돌릴 수 없습니다.

다른 활성 월이나 과거 확정본이 해당 기준을 사용하면 초기화를 거절하고 사용 월을 표시합니다. 초기화 범위 확인 후 버전·파일·월 수정 순서가 바뀌면 다시 확인해야 합니다. 월 작업 초기화와 별개이며, 화면에서 버튼을 추가하는 작업만으로 실제 기준을 삭제하지 않습니다.


## BOM 품목별 추가와 해결 가이드 연결

- 기준 관리 → BOM → **BOM 품목 추가**에서 제품 품번·촉매 품번·제품 1개당 소요량·촉매사를 입력합니다. 고객사는 새 제품을 추가할 때 선택 입력합니다.
- 마감 검토의 연결 누락 → 해결 방법 → BOM 관리로 이동을 누르면 문제의 촉매 품번과 확인된 촉매사가 미리 채워집니다. 제품 품번과 소요량은 추측해서 채우지 않습니다.
- **BOM 저장·이번 달 적용**은 현재 월에 적용한 BOM을 바탕으로 새 버전을 만들고 그 월에 적용하는 작업을 한 번에 처리합니다. 초기 BOM이 전혀 없을 때도 한 행부터 시작할 수 있습니다. 적용 전 파일·버전만 있으면 먼저 기존 기준을 적용해야 합니다.
- 이미 등록된 제품이면 기존 촉매 구성에 추가합니다. 동일 제품의 고객사별 반복 행에는 함께 추가하며, 다른 제품과 기존 구성·고객사는 보존합니다. 이미 등록된 촉매의 중복 추가, 사용구분 충돌, 촉매사 충돌, 4종 초과, 0 이하 소요량은 저장하지 않습니다. 기존 소요량 수정·삭제나 여러 행 교체는 엑셀 수정본 등록을 사용합니다.
- 이전 버전·다른 월·확정본은 바뀌지 않습니다. 새로 시작하는 월은 적용 기간에 맞는 새 기준을 이어받습니다. 제품의 납품 경로가 빠졌으면 경로·공장 연결도 보완한 뒤 마감 검토에서 다시 계산합니다.


## 해결 가이드에서 수정 화면 준비

- 단가 문제 → 촉매 단가 관리: 해당 촉매 품번과 기존 기본 단가를 불러옵니다. 미등록이면 단가 입력란을 준비합니다. 같은 품번의 단가가 여러 개면 기존 값을 보여 주고 적용할 단가를 직접 입력하게 합니다.
- 경로 문제 → 경로·공장 관리: 이번 달 BOM에서 촉매가 들어가는 정확한 제품을 찾고 적용 중인 경로·공장·창고·집계 항목을 불러옵니다. 후보가 여러 개면 해당 제품들의 경로만 선택 목록에 표시합니다. 연결 제품이 없으면 촉매 품번을 제품 품번으로 대신 넣지 않고 제품 입력을 기다립니다.
- 수정값과 변경 사유를 입력한 뒤 **수정 저장·이번 달 적용**을 누르면 새 버전 저장과 이번 달 채택을 한 트랜잭션으로 처리합니다. 다른 품목과 다른 월의 적용 버전은 유지합니다.
- 원본 누락 → 자료 등록: 누락 종류가 확인되면 자료 종류·기준월을 준비하고, 등록 파일이 있으면 내용과 해당 품번 검색을 엽니다. 여러 자료가 관련되면 자료별 바로 선택 버튼을 표시합니다. 기간 확인 체크와 파일 채택은 사용자가 합니다.
- 제품 납품·BOM 연결 / 촉매사·ERP 수량 대조: 읽기 전용 조회를 자동 실행하고 문제 품번을 검색 조건에 넣습니다.
- 이월·미마감·공장 수량·단가·마감처·촉매사 차이 조정: 해당 촉매와 수정 항목을 열고 기존 저장값·사유·근거를 준비합니다. 제품 수량 구분은 관련 제품을 앞에 표시하며 다른 제품의 저장값도 유지합니다.
- 가이드 이동만으로 값을 저장·승인하지 않으며, 작성 중인 값이 있을 때 이동을 막아 입력을 보존합니다.


## 업체명 선택과 오타 방지

- BOM 추가, 경로 수정, 기준 관리의 촉매사는 희성·유미코아 선택 목록을 사용합니다. 화면 입력뿐 아니라 저장 시에도 허용된 업체명인지 검사합니다.
- BOM 고객사는 사용 중인 선택 목록에서 선택합니다. 미지정은 허용하며, 새 고객사는 선택 목록 관리에서 추가한 뒤 바로 선택할 수 있습니다.
- 희성촉매(주)·한국유미코아촉매 등 명시적으로 알려진 촉매사 표기는 같은 회사로 인식합니다. 유사한 철자의 이름을 임의 추정하지 않으며 기존 원본 표기와 고객사 값은 일괄 변경하지 않습니다.


## 같은 촉매를 여러 제품·고객사에 추가

- BOM은 제품을 기준으로 촉매 구성(촉매 품번·제품 1개당 소요량)을 보관합니다. 같은 촉매가 다른 제품에도 들어가면 제품별 행에 반복 기재되는 것이 정상입니다.
- 화면 상단에서 촉매 품번·촉매사를 한 번 지정하고, **+ 제품 추가**로 제품별 품번·소요량을 입력합니다. 제품마다 **+ 고객사 추가**로 등록된 고객사를 여러 곳 선택합니다. 신규 업체명을 자유 입력하는 기능은 아닙니다.
- 같은 제품·여러 고객사는 동일 촉매 구성의 고객사별 행으로 저장됩니다. 계산에서는 동일 제품의 같은 구성을 한 번만 적용하며, 고객사별로 구성이 다르면 계산을 중단합니다. 최종 마감처와 납품 배분은 경로 기준으로 결정합니다.
- 기존 제품에 고객사를 추가하면 기존 촉매 전체 구성을 복사합니다. 같은 촉매가 같은 소요량으로 이미 있으면 중복 추가하지 않고 새 고객사 연결만 추가할 수 있습니다. 다른 소요량이면 기존 기준을 조용히 덮어쓰지 않고 오류를 표시합니다.
- 여러 제품을 한 번에 검증하고 하나의 버전·한 번의 월 적용으로 저장합니다. 한 제품이라도 잘못되면 전부 저장하지 않습니다. 같은 제품 입력·중복 고객사·잘못된 소요량은 차단합니다.


## 선택 목록 관리

- 기준 관리 상단 **선택 목록 관리**, 또는 경로·공장·마감처·고객사·창고 선택란 옆 **목록 관리**를 누릅니다. 창을 열어도 입력 중인 품번·소요량·사유는 유지됩니다.
- 관리할 목록을 선택하고 새 이름을 적어 **목록에 추가**를 누릅니다. 닫으면 입력 화면의 선택 목록에 바로 반영됩니다.
- 등록된 BOM의 고객사, 경로 기준의 경로·상세 공장·마감처·창고, 채택한 제품·반제품 수불의 창고명을 기존 선택지로 가져옵니다. ERP 촉매 입고의 임의 거래처를 최종 마감처로 추정하지 않습니다.
- **사용 중지**는 앞으로 선택할 목록에서 제외하는 기능입니다. 이미 적용된 기준·월별 조정·확정본의 이름을 바꾸지 않습니다. 잘못된 이름은 올바른 이름 추가 → 잘못된 이름 사용 중지 → 해당 기준에서 다시 선택하여 저장·적용 순서로 고칩니다. 다시 사용도 가능합니다.
- 목록은 월별 실적과 별도로 이 자료 폴더 전체에서 공유합니다. 직접 등록한 선택지는 월 초기화나 기준 초기화 후에도 유지합니다. 원본에서 가져온 선택지만 있는 경우 해당 원본·버전을 초기화하면 더 이상 후보로 나타나지 않을 수 있습니다. 목록 변경 이력은 DB에 보관하며 계산 기준을 자동 수정하지 않습니다.
- 공장 이름을 목록에 추가하는 것만으로 경로가 연결되지 않습니다. 제품의 경로 기준에서 납품 경로·상세 공장·ERP 마감처·집계 창고를 직접 연결해야 합니다.
- 집계 창고는 **+ 집계 창고 추가**로 여러 곳을 선택합니다. 촉매별 마감처가 다른 경로는 **촉매별로 다른 마감처**를 선택하고 촉매 품번마다 마감처를 지정합니다. 중복 촉매·빈 마감처는 저장하지 않습니다.
- 촉매사(희성·유미코아), 집계 자료·수량 항목·처리 상태는 프로그램이 지원하는 고정 선택지입니다. 품번·소요량·단가·변경 사유·비고는 직접 입력합니다.
- DB 형식은 6입니다. 기존 형식 5는 실행 시 자동 백업 후 선택 목록 이력 테이블만 추가하며, 업무 자료와 기준 버전은 보존합니다.
