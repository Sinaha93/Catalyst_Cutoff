# 기준 관리와 월 작업 초기화

2026-10-14 보완. 프로그램의 **기준 관리** 메뉴에서 사용합니다.

## 엑셀과 프로그램의 역할

| 항목 | 관리 방법 |
|---|---|
| ERP 수불·촉매사 출하·적송재고·월계획 | 매월 받은 엑셀/PDF 원본 등록 |
| 제품별 촉매 구성·소요량(BOM) | 기존 BOM 엑셀 수정 → 후보 등록 → 변경 비교 → 적용 기간을 지정해 기준 버전 저장 |
| 제품별 경로·집계 자료/창고/수량 항목·상세 공장·ERP 마감처 | 최초 경로표를 등록한 후 프로그램에서 수정. 엑셀은 검토·일괄 등록 용도 |
| ERP 등록 단가 | 받은 단가 엑셀 등록 |
| 가단가·정단가 예외 | 프로그램 기준 버전에 적용 기간·사유·근거 저장. 특정 월에만 필요한 수정은 월 마감 검토에서 입력 |
| 마감 배분·미정산·이월 수정 | 해당 월 작업에서 관리 |
| 마감 결과 | 확정본에서 엑셀 생성 |

프로그램 기준을 적용한 항목은 자료 등록 화면에서 다른 엑셀을 채택해 계산을 우회할 수 없습니다. 새로운 파일은 기준 관리의 후보로 사용합니다. BOM 구성을 프로그램에서 별도 편집하는 기능은 의도적으로 제공하지 않습니다.

## 최초 등록과 수정

1. 자료 등록에서 기존 경로표/BOM 또는 단가 예외표를 올립니다.
2. 기준 관리에서 기준 종류와 **등록한 엑셀에서 가져오기**를 선택합니다.
3. 적용 시작월과 사유를 입력합니다. 종료월은 필요할 때만 입력합니다.
4. **기준 변경 내용 비교**에서 추가·제외·변경 행을 확인하고 **새 기준 버전 저장**을 누릅니다.
5. **이번 달 적용 전 차이 보기**에서 현재 월의 기준과 비교한 뒤 **이 버전을 이번 달에 적용**합니다.

이후 경로와 단가 예외는 저장된 버전을 불러와 화면에서 수정할 수 있습니다. 왼쪽에서 품번·경로를 선택하고 오른쪽에서 세부 공장, ERP 마감처 등을 수정합니다. 같은 품번에 여러 경로 행을 등록할 수 있습니다. 새 버전에서 행을 제외해도 이전 버전은 남습니다.

경로의 **배분에 집계**를 해제하면 이동 추적용 기준으로만 보관합니다. 중간 납품처와 후속 현대·기아 창고 수량을 중복 집계하지 않도록 집계 지점을 지정합니다. 같은 원본 수량이 여러 상세 공장에 연결되면 월별 공장 수량 구분이 계속 필요합니다. 글로비스 경로는 실제 입고 자료만 사용하며 일반 수불 비율로 바꿀 수 없습니다. 촉매별 별도 ERP 마감처가 있는 기존 구조도 보존합니다.

## 적용 기간과 과거 자료

- 새 월 작업을 처음 열 때 해당 월에 유효한 기준 버전이 자동 연결됩니다. 유효한 버전 중 적용 시작월이 가장 최근인 것을 선택하고, 시작월이 같으면 최신 버전을 선택합니다.
- 이미 열어 둔 월의 기준은 자동으로 바뀌지 않습니다. 변경 비교 후 명시적으로 적용해야 합니다.
- 버전의 적용 기간은 그 버전에 포함된 전체 기준표에 적용됩니다. 일부 행만 바꿔도 나머지 행을 유지한 새 전체 버전으로 저장합니다.
- 단가 예외를 종료하려면 해당 예외를 제외한 새 버전을 등록할 수 있습니다. 종료월이 지난 버전은 새 월에 자동 선택되지 않습니다.
- 적용 기준 변경 시 관련 월별 판단의 근거가 바뀌면 재검토가 표시됩니다. 다른 품목만 변경한 경우 동일한 품목의 기준 내용은 유지됩니다.
- 과거 확정본은 기준과 원본 해석 결과를 함께 고정하므로 이후 기준 수정으로 바뀌지 않습니다.

## 해당 월 입력 다시 시작

**월 작업 초기화 → 이 월의 입력 다시 시작 → 사유 입력 → 이전 초안을 보관하고 초기화** 순서입니다.

초기화되는 항목: 작업 메모, 월별 이월 수정, 원천 선택 판단, 보류·해소, 수량·단가 수정, 예외 매핑, 공장별 분할 입력. 예전 엑셀 배분 입력의 채택도 해제합니다.

보존하는 항목: 등록 원본과 PDF 인식 검토본, 채택한 업무 원본, 채택한 프로그램 기준, 전월 확정 이월 연결, 모든 과거 확정본·출력·감사 이력. 이전 초안의 입력 내역도 DB에서 삭제하지 않고 보관 상태로 남깁니다. 화면에는 보관 초안의 날짜와 메모 목록을 표시합니다.

확정된 월은 먼저 **새 확정 버전 작업 시작**을 선택해야 초기화할 수 있습니다. 초기화 후에는 업무 판단을 다시 입력해야 하며 자동으로 마감 확정하지 않습니다. 프로그램 전체 자료 삭제 기능은 아닙니다.
