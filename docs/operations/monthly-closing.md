# 월 통합 마감 검토 운영 안내

마감 검토의 품목별 확인 메시지, 계산 오류, 확정 화면의 전체 확인 항목 옆에는 **해결 방법** 버튼이 있습니다. 원인과 처리 순서를 읽은 뒤 가이드 안의 이동 버튼으로 BOM·경로·단가 카드, 현재 품목의 조정 항목, 계산 근거 또는 전월 이월 연결 화면을 바로 열 수 있습니다. 입력 중에는 설명을 볼 수 있지만 이동은 저장·작성 취소 후 가능합니다. 이동은 화면 선택만 하며 자료를 수정하거나 저장하지 않습니다. 상단 **사용 가이드 → 확인 메시지 해결**에서도 같은 설명을 볼 수 있습니다.

추가 조정의 **수정 항목 설명**·**적용 구성 설명** 버튼은 현재 항목의 가이드를 화면 위에 엽니다. 작성 중에도 볼 수 있고 닫기 또는 Esc로 돌아오면 입력값이 유지됩니다. 설명을 여는 것만으로 수정이나 저장이 일어나지 않습니다. 상단 **사용 가이드 → 추가 조정 이해하기**에서도 같은 설명을 볼 수 있습니다. 계산 기준 확인·이월 수정·단가·마감처 연결·제품 수량 구분·촉매사 마감 차이 확인의 뜻, 사용 시점, 숫자 예시, 입력 순서, 저장 결과와 적용 구성 네 가지의 자료 출처를 설명합니다.

## 화면 이동

상단 **사용 가이드**에서 화면 이미지와 함께 6단계 마감 순서를 따라갈 수 있습니다. 월 작업을 열기 전에도 가이드를 볼 수 있습니다. 자료 준비, 미마감·공장 수량 입력, 저장·작성 취소·수정 해제, 기준 관리, 용어와 문제 해결을 설명합니다. 화면 이미지는 설명용 합성 자료를 사용했으며 클릭하면 확대됩니다. 가이드에서 실제 작업 화면으로 갔다가 돌아와도 보고 있던 단계는 유지됩니다.

상단 메뉴는 스크롤 위치 이동이 아니라 각각의 화면으로 전환합니다. 현재 마감월은 메뉴 간에 유지되고 주소의 `#` 뒤에 열린 화면이 표시됩니다.

- 월 작업: 마감월 선택, 메모, 접어서 보관한 초기화 메뉴
- 자료 등록: 원본 등록·확인·채택
- 마감 검토 → 전체 검토: 품목별 결과, 확인 항목, 필요할 때 여는 추가 조정
- 마감 검토 → 미마감 조정: 저장된 미마감 수량을 불러와 필요한 칸만 수정
- 마감 검토 → 공장별 수량 조정: 현재 적용 수량을 표시하고 변경할 공장만 수정
- 마감 검토 → 계산 근거: 촉매사·ERP 대조, 제품 납품·BOM, 단가·월계획 및 기존 검산 자료를 선택해서 조회
- 확정·출력: 월 확정, 새 버전 작업, 이월 연결, 엑셀 및 백업
- 기준 관리: 경로·공장, BOM 버전, 단가 예외

저장하지 않은 입력이나 처리 중인 작업이 있으면 화면 이동을 막고 안내합니다. 브라우저 뒤로가기도 입력을 버리지 않습니다. 일반 마감 조정은 하위 메뉴에서 바로 열며, 계산 기준·이월·단가 등의 예외 수정은 전체 검토의 `추가 조정 열기`에 있습니다.

## 작업 순서

1. 월 작업을 열고 원본을 등록·검산·채택합니다. 희성과 유미코아 적송 PDF는 전월 말 기준입니다. PDF의 발행일은 재고 기준월과 구분합니다.
2. 상단 `마감 검토`에서 전체 촉매를 조회합니다. 현재 BOM·원천 실적·전월 확정 미마감·유미코아 PDF를 합쳐 품목 범위를 정합니다. 당월 수량 없는 품목은 구분 표시하며 양산 여부를 임의 판단하지 않습니다.
3. 원천 차이는 촉매사 구성, ERP·장부 구성, 전월 확정 미마감 또는 별도 구성 중 근거에 맞게 선택합니다. 이월과 입고를 서로 다른 자료에서 임의 합산하지 않습니다. 선택 이유와 근거를 저장합니다.
4. 이월 수정은 OCR 정정과 별도입니다. 원본 PDF 수량, 인식 정정, 업무 수정, 적용 값을 보존합니다. 수정 해제는 원래 기준으로 복원하며 이력은 남습니다.
5. 일반 품목은 별도 미마감 입력이 없으면 전월 이월 + 당월 입고 전량을 마감합니다. 미마감 0을 따로 저장하지 않습니다. 전월 미마감도 기본적으로 전량 해소하며, 남길 물량이 있을 때만 미마감 조정에서 수정합니다. 이미 저장한 미마감은 유지하고 근거가 바뀐 수정은 재검토합니다. 글로비스 포함 품목은 실제 제품 입고 조건과 미마감 수량을 별도로 확인합니다. 비교 보고서가 없는 것만으로 원천 구성 선택을 요구하지 않으며 실제 수량 차이·필수 원본 누락은 계속 검토합니다.
6. 상세 공장 자동 배분과 ERP 지역 합계를 확인합니다. 제품 수량 구분은 중복된 원본 총량을 완전히 분할해야 합니다. 촉매 수량 수정의 공란은 자동, 0은 명시적 0이며 차이를 다른 공장에 자동 배분하지 않습니다. 글로비스는 실제 입고×BOM으로 고정합니다.
7. 단가·금액과 미정산을 확인하고 차이가 없으면 확정합니다. 금액은 상세 공장 행별 수량×단가를 원 단위 사사오입한 후 합산합니다. ERP 금액도 해당 행의 합계입니다.
8. 같은 확정 버전에서 엑셀을 출력합니다. 희성 출하 첫 시트의 표시 값을 보존하고 가공 시트를 생성합니다. 유미코아, ERP 지역별, 미정산, 수량 검산, 수정 이력, 원본 해시가 같은 통합문서에 들어갑니다. ERP·현대기아 자동 업로드 규격으로 인증된 파일은 아닙니다.

## 이력과 다음 달

- 수정은 추가 이력으로 저장합니다. 관련 원천·경로·계산 기준이 달라진 수정만 재확인 대상으로 표시합니다. 오래된 수정은 계산에 적용하지 않으며 미해결 상태로 남습니다.
- 확정본에는 적용 값, 자동 계산 값, 단가, 상세 공장, 미마감 내역, 정규화된 원천 행과 원본 해시를 동결합니다. 데이터베이스에서도 확정본 수정·삭제를 차단합니다.
- 재작업 사유를 입력하면 편집을 다시 열 수 있습니다. 재확정은 새 버전입니다. 이전 확정본은 그대로 조회·재출력할 수 있습니다.
- 다음 달은 전월 확정본을 지정해 미마감를 연결합니다. PDF 이월과 차이가 있으면 선택 근거를 남깁니다. 전월이 재확정되어도 다음 달 연결을 자동 교체하지 않으며 새 버전 알림과 재검토가 필요합니다.
- 전월 미마감의 단가·구분을 보존합니다. 당월 이번 달 추가 미마감의 단가와 다르면 별도 내역으로 남습니다. 같은 마감처에 단가별 미마감가 여럿이면 이월분 마감 대상을 구분합니다. 명시적인 단가 수정은 변경 사유와 이전 값을 남깁니다.

## 원천 밖의 품목과 예외

- 현재 BOM에 없더라도 실제 입출고나 이월이 있으면 검토 대상입니다. ERP가 현대모비스 단일 마감으로 명시한 경우 근거를 연결합니다. 다른 공장은 고객사 이름만으로 상세 공장을 추정하지 않습니다.
- BOM 밖·촉매 직사급·A/S·개발 이벤트 등은 이번 달 마감처 연결을 근거와 함께 등록할 수 있습니다. 월별 연결은 일반 배분 경로에 적용하며 원래 기준표를 변경하지 않습니다. 기존 글로비스 실제 입고 경로는 그대로 유지하고 수동 비율로 대체할 수 없습니다.
- 유미코아 원문 마감 수량을 보존하며 미마감 처리 후 총량이 다르면 차이를 표시합니다. `촉매사 마감 차이 확인`에서 정산 시점 차이 등의 사유·근거를 남길 수 있으며 수량은 변경하지 않습니다. 관련 원천·미마감가 바뀌면 재확인합니다. 원문 잔량을 희성 미마감로 해석하지 않습니다.
- 과거 보고서의 당월 미정산·최종 마감은 비교 자료이며, 과거 결과를 맞추기 위해 자동 미마감나 고정 배분으로 채택하지 않습니다.
- 과거 월 재현 시험에서는 기존 보고서에 명시된 미마감 수량 조정·A/S 정산·공장 구분을 시험 입력으로 기록할 수 있습니다. 기본 비율과 당시 명시 입력을 구분하며, 다음 달의 영구 규칙으로 복제하지 않습니다.
- 전량 미마감가 확인된 품목은 생산 배분 근거 없이 마감 0개로 검산할 수 있습니다. 글로비스 실제 입고가 있거나 해당 원본이 누락되면 확정을 차단합니다. 전량 미마감 품목도 촉매사 가공 시트에 표시됩니다.
- 같은 ERP 마감처의 알려진 명칭 차이는 계산에서 통합하되 원문을 보존합니다. 서로 다른 상세 공장은 합치지 않습니다.
- 전월 확정 미마감가 있는 품목은 다음 달 원본 등록 전에도 검토 대상입니다. 자료 미등록을 당월 거래 없음이나 이월 0으로 표시하지 않습니다.

## 저장과 복구

DB 스키마 5입니다. 기존 1~4 스키마는 SQLite backup API로 백업한 후 한 트랜잭션에서 전환합니다. 원본 파일은 해시로 검증합니다. 동시 저장은 월 수정 순서가 맞지 않으면 거절합니다. 프로그램 기준 관리와 월 작업 초기화는 [별도 운영 안내](master-management.md)를 확인합니다.

월 작업 목록의 **삭제**는 확인창에서 선택한 월의 초안·메모·수정 이력·확정본·등록 자료와 그 월에서만 사용하는 보관 원본·출력 파일을 완전히 삭제합니다. 현재 선택한 월이면 작업 선택도 해제합니다. 같은 월을 다시 열면 새 작업이며 프로그램 안에서 복원할 수 없습니다. 새 삭제 이력이나 자동 백업을 만들지 않습니다. 기존에 따로 저장한 백업 ZIP과 프로그램 밖 원본·다운로드 파일은 삭제하지 않습니다.

다른 월이 이 월의 확정본을 이월로 참조하면 해당 연결이 남아 있는 동안 삭제를 거절하고 연결된 월을 안내합니다. 다른 월·확정본·프로그램 기준에서 공유하는 보관 원본과 전역 BOM·경로·단가 예외 기준은 유지합니다. 월 삭제는 한 DB 트랜잭션으로 처리하고, 확정본의 일반 수정·삭제 방지 트리거는 월 삭제 후에도 유지합니다. 파일 사용 중 등으로 일부 실제 파일을 지우지 못하면 화면에 경고를 표시합니다.

`자료 전체 백업`은 일관된 DB와 등록 원본·출력 파일 및 SHA256 명세를 ZIP으로 저장한 뒤 다시 열어 검증합니다. 복구 시 새 빈 자료 폴더에 압축을 풀고 그 폴더를 선택합니다. 현재 사용 중인 폴더 위에 덮어쓰지 않습니다. 백업에는 민감한 업무 자료가 포함되며 GitHub에는 올리지 않습니다.

실제 9월 자료 검증은 별도의 복사본에서 수행합니다. 기능 검증을 위한 가상 자료의 확정과 실제 월 마감의 업무 승인은 구분합니다.


2026-10-15 단가 등록 단순화: 자료 등록은 ‘촉매 단가’ 파일 하나만 받습니다. 가단가·예외 단가는 마감 검토에서 품목별 ‘단가’를 선택해 마감처별 적용값과 정단가/가단가, 사유·근거를 저장합니다. 별도 예외 단가 파일 등록 UI는 제거했습니다. 기존 단가 기준·파일·확정 이력은 보존하며 화면 수정값의 우선 적용 및 기준 변경 시 재확인 동작을 유지합니다.


2026-10-15 자료 화면 분리: 월별 실적과 월계획은 자료 등록에서 처리하고, BOM·촉매 단가·경로는 기준 관리에서 파일 등록부터 비교·저장·이번 달 적용까지 처리합니다. 단가 파일의 입력 위치도 기준 관리로 이동했습니다. 이번 달 가단가는 마감 검토에서 수정합니다.
