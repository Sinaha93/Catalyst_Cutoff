# W1 실행·저장 기반 구현 기록

2026-10-13. 사용자의 다음 단계 진행 요청에 따라 W1을 구현했습니다. 현재 작동하는 범위는 월 작업 생성·다시 열기, 작업 메모 자동 저장, 변경 이력 조회, 서비스 종료·재실행 후 복원입니다. 실제 업무 수량·원본 자료는 아직 연결하지 않았습니다. 화면의 준비 중 기능은 실행되지 않습니다.

## 구현

- Python / FastAPI가 같은 출처에서 React / TypeScript 빌드와 API를 제공합니다. `127.0.0.1`의 사용 가능한 포트로만 실행합니다.
- 최초 실행에서 코드 폴더 밖의 자료 보관 폴더를 선택합니다. SQLite 스키마 버전 1, 월 작업, 활성 초안, 개정별 변경 이력을 저장합니다. 같은 월 시작은 기존 초안을 돌려줍니다.
- Windows 파일 잠금으로 같은 자료 폴더의 서비스 중복 실행을 차단합니다. 프로세스가 강제 종료돼도 OS 잠금이 해제되어 다음 실행이 가능합니다.
- 메모는 입력이 멈춘 뒤 자동 저장합니다. 변경과 감사 이력을 한 트랜잭션으로 저장하며 실패하면 함께 롤백합니다. 실패 응답에서도 화면 입력은 남고 재시도할 수 있습니다.
- 예상 개정 번호를 검사해 다른 창의 저장을 조용히 덮어쓰지 않습니다. 최신 저장본을 다시 읽기 전 필요한 입력을 복사하도록 안내합니다.
- 쓰기 요청은 같은 출처와 실행 세션 토큰을 검사합니다. 외부 Host, 외부 Origin, 이전 실행의 토큰은 허용하지 않습니다. 화면 정적 파일 이외 업무 폴더는 웹 경로로 제공하지 않습니다.
- 기존 상단 메뉴·좌측 목록/우측 상세 방향을 반영했습니다. Figma와 기존 시안은 변경하지 않았고 최종 UI 확정으로 취급하지 않습니다.

## 검증

검증 환경: Windows, Python 3.12.14, Node.js 24.15.0, 설치된 Microsoft Edge. 테스트는 가상 메모와 독립된 임시 폴더를 사용합니다.

| 검증 | 결과 |
|---|---|
| 백엔드 `pytest -q` | 12개 통과. 복원·같은 월 재시도·동시 시작·오래된 개정·잘못된 월·감사 저장 실패 롤백·DB 미래 버전 거절·프로세스 강제 종료 후 잠금 해제·로컬 세션·저장 오류 응답 |
| TypeScript와 Vite 빌드 | 통과 |
| Edge 브라우저 통합 검증 | 월 생성→메모 자동 저장→새로고침→같은 월 열기→저장 실패 및 재시도→다른 창과 개정 충돌→최신본 읽기→정상 종료→새 프로세스 재실행 및 복원 통과 |
| 화면 너비 | 1920·1536·1280·768·360에서 문서 전체 가로 넘침 없음. 1920×1080 캡처 확인 |
| 폴더 선택 런타임 | Tk 창 생성·종료 확인. 실제 사용자의 폴더 선택은 최초 실행에서 수행 |

브라우저 통합 검증 중 서비스의 수신 준비 전에 주소를 알리는 경합을 발견해 수정했습니다. 준비 완료 후에만 주소를 반환하고 브라우저를 엽니다.

백엔드 검증 도구에서 Starlette의 httpx TestClient 사용 중단 예정 경고 1건이 있습니다. 검증은 통과했으며 업무 저장 실패가 아닙니다. 추후 테스트 도구 전환 시 처리합니다.

## 남은 범위

다음 W2는 원본 보관·자료 역할/기간·추출 근거와 적송재고 PDF 인식·검산입니다. W1 메모는 마감 수량 수정이나 전월 이월 연결을 대신하지 않습니다. 자료 등록·계산·확정·출력·백업·과거 자료 이관·단독 EXE 배포는 아직 미구현입니다. 새 월 작업은 기초 자료 연결 전 상태로만 생성하며 수량 0이나 마감 완료로 표시하지 않습니다.

기본 실행은 폴더 선택을 기억하고 명시적인 `--data-dir` 실행은 테스트/별도 자료 실행을 위해 기본 설정을 변경하지 않습니다. 일반 설치는 `setup.ps1`, 실행은 `start.ps1`입니다. 의존성은 Python 전체 버전 목록과 npm 잠금 파일에 기록했습니다. Codex 번들 Python에서 ensurepip가 실패한 환경은 이미 생성된 격리 환경에 외부 pip의 `--python` 옵션으로 설치해 검증했습니다. 일반 설치 스크립트는 표준 Python의 venv/ensurepip를 전제로 합니다.

구현 시 확인한 공식 문서: [FastAPI 서비스 수명](https://fastapi.tiangolo.com/advanced/events/), [SQLite Python API](https://docs.python.org/3/library/sqlite3.html), [Vite 빌드 환경](https://vite.dev/guide/).
