# 월 마감 UI/UX 작업 흐름 정리

2026-10-14. 사용자 요청에 따라 실제 프로그램에 적용한 변경과 검증 기록입니다. UI 확정 후 작성할 사용자 가이드와 구분합니다.

## 설계 판단과 참고 근거

마감 업무는 자료를 교체하거나 계산 근거를 확인한 뒤 다시 수량을 조정하는 일이 있습니다. 따라서 순서를 안내하되, 앞 단계를 다시 방문할 수 있는 상단 메뉴를 유지합니다. 저장하지 않은 수정이 있을 때만 기존 이동 제한을 유지합니다.

## 적용 내용

1. **월 작업:** 자료 등록 → 마감 검토 → 확정·출력의 세 단계와 이어서 할 일을 안내합니다. 등록 파일 수, 실제 계산 상태, 확정 여부를 사용하며 임의의 완료율은 표시하지 않습니다.
2. **자료 등록:** 이번 달 원본 / 기준·계획 자료 / 추가 비교 자료로 묶었습니다. 종류별 등록·사용 상태를 표시하고, 파일을 선택하면 해당 내용으로 이동합니다. 보관·읽기와 이번 달 사용 선택은 구분합니다. 확정 후에는 조회·원본 다운로드를 허용하고 변경은 잠급니다.
3. **마감 검토:** 왼쪽 목록과 오른쪽 상세를 유지합니다. 미마감·공장별 수량 화면은 입력칸을 먼저 표시하고 상세 배분 결과·근거는 아래에서 펼칩니다. 바로 이동할 때 품목 선택을 유지하고, 다음 품목 버튼을 제공합니다. 검색에 상세 공장명을 포함합니다. 데스크톱에서는 목록과 상세를 각각 스크롤하며 화면 높이에 맞춥니다.
4. **수정:** 추가 조정은 펼쳐서 사용합니다. ‘저장된 수정값 해제’와 ‘작성 취소’를 구분하고, 수정 사유·근거 입력 안내와 저장 상태를 가까이 배치했습니다. 기존 수정 이력·빈칸 처리·미저장 이동 제한을 유지합니다.
5. **확정·출력:** 검토 결과 확정과 보고서 다운로드를 두 영역으로 구분합니다. 엑셀 생성 후 다운로드를 시작하고 재다운로드 링크를 제공합니다. 새 버전을 확정하면 출력 대상도 새 버전으로 전환합니다. 백업·재작업·전월 이월 연결은 별도 접기 영역에 둡니다.
6. **상태 일치:** 초기 화면이 사용하는 월 목록 API에도 확정 잠금 상태를 포함했습니다. 확정된 월이 새로고침 후 ‘작업 중’으로 표시되는 문제를 수정했습니다.

상단 메뉴, 메뉴별 독립 화면, 1920×1080 기준을 유지합니다. 계산·배분 규칙과 엑셀 종합표·차트 양식은 이번 UI 작업에서 변경하지 않습니다.

## 검증

- TypeScript 검사 및 Vite 배포 빌드 통과.
- 임시 DB로 자료 등록·교체, 기간 확인, 저장 실패 시 입력 보존, 미마감 수정·해제, 미저장 이동 차단, 마감 확정, 실제 브라우저 다운로드, 재확정과 새 버전 선택을 브라우저 시험으로 확인했습니다 (`workspace.mjs`, `closing.mjs` 통과).
- 월 목록과 상세 API의 확정·재작업 상태 일치 회귀 검증을 추가했습니다. `test_closing.py`, `test_workspace.py` 합계 26개 통과.
- 실제 9월 시험 데이터는 조회만 하며 1920×1080, 1536×864 화면을 확인했습니다. 가로 넘침·페이지 오류가 없고 전후 초안이 일치했습니다. 원본과 9월 수정값을 UI 시험용으로 바꾸지 않습니다.
- 화면 최종 확정 및 사용자 가이드 작성은 별도 단계입니다.
