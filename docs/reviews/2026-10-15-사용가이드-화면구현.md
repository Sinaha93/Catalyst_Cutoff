# 프로그램 사용 가이드

사용자 요청: 별도 메뉴에서 실제 화면 이미지와 함께 이해하기 쉽게 설명합니다.

- 상단 `사용 가이드` 메뉴를 추가했습니다. 월 선택 전과 월 목록 조회 실패 시에도 읽을 수 있습니다. 다른 업무 화면과 마찬가지로 미저장 입력·처리 중에는 이동을 막습니다.
- 6단계로 월 선택, 자료 등록·사용 선택, 전체 검토, 미마감, 공장별 수량, 확정·엑셀 출력을 설명합니다. 다음 단계 버튼을 화면 이미지 위에 배치했습니다.
- 매월 파일과 저장된 기준을 구분하고, 미마감 100·20·10·5개 예시와 빈칸·0, 저장·작성 취소·수정 해제의 차이를 설명했습니다.
- 기준 관리, 적용 기간, 상세 공장·ERP 마감처 등 용어, 검색 가능한 문제 해결 안내를 제공합니다.
- 합성 테스트 저장소에서 실제 화면 이미지 7장을 촬영했습니다. 운영 자료나 실제 수량이 이미지에 포함되지 않습니다. 화면은 클릭해 확대하고 닫기·Esc로 돌아올 수 있습니다.
- 가이드는 업무 값을 저장·수정하지 않습니다. 실제 작업으로 이동한 뒤 돌아왔을 때 보고 있던 단계·주제를 유지합니다.

검증: TypeScript·Vite 빌드, Edge 가이드 브라우저 검증. 월 미선택·조회 실패 상태, 모든 단계 이미지 로딩, 확대·Esc, 자료 목록, 수량 예시, 문제 검색, 업무 값 변경 없음, 등록 전 파일 선택 보존, 미저장 메모 중 이동 차단을 확인합니다. 화면은 1920×1080·1536×864와 좁은 화면에서 검토합니다. 기존 월 작업·통합 마감 브라우저 검증도 통과했습니다.

캡처 재생성은 `frontend/tests/guide.mjs`, 이미지 원칙은 `frontend/public/guide/README.md`에 기록했습니다.
