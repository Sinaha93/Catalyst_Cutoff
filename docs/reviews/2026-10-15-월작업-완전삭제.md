# 월 작업 완전 삭제

사용자는 과거 월을 목록에서 숨기는 방식이 아니라 실제로 삭제하기를 원했습니다. 숨김·복원 기능은 제외하고 월 목록의 삭제 버튼을 구현했습니다. 기존 스키마 5를 유지하며 삭제 기능 때문에 별도 이력이나 자동 백업을 생성하지 않습니다.

삭제 대상은 선택한 월의 모든 초안, 메모, 원본 등록·검토·선택 내역, 월별 판단과 수정 이력, 확정본, 출력 기록입니다. 이 월에서만 참조하는 보관 원본·출력 파일도 정확한 개별 파일 경로를 검증해 제거합니다. 기존 사용자 백업 ZIP과 프로그램 밖 원본·다운로드 파일은 변경하지 않습니다.

다른 월이나 프로그램 기준에서 공유하는 파일은 유지합니다. 다른 월이 삭제할 확정본을 이월로 참조하면 삭제를 거절합니다. 전역 BOM·경로·단가 예외 버전은 월 작업 삭제와 독립적으로 유지합니다.

DB 삭제는 한 트랜잭션으로 수행합니다. 확정본 삭제 방지 트리거는 이 명시적 월 삭제에서만 트랜잭션 안에서 해제·복원합니다. 일반 확정본 수정·삭제는 계속 차단됩니다. 실제 파일을 지우지 못하면 완료 안내에 경고를 표시합니다.

프런트엔드는 확인창에 대상 마감월과 삭제 범위를 표시합니다. 확인 취소는 아무것도 바꾸지 않습니다. 현재 선택한 월을 삭제하면 선택과 상세 표시를 해제합니다. 새로고침해도 삭제한 월이 다시 나오지 않으며 같은 월을 새로 열면 새 초안입니다.

검증: 월 완전 삭제·확정본·원본·출력 제거, 공유 기준 보존, 이월 의존 삭제 차단, 오래된 수정 순서 거절, 실패 시 롤백 및 다른 월 보존. 브라우저에서는 확인·취소, 세션 토큰 보호, 목록·현재 선택 해제, 재실행 후 새 초안을 검증합니다. 모든 검증은 별도 합성 자료 저장소를 사용합니다.
