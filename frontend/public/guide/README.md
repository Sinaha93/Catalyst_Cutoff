# 사용 가이드 화면 이미지

월 작업, 자료 등록, 전체 검토, 미마감 조정, 공장별 수량 조정, 확정·출력, 기준 관리의 실제 UI 화면입니다.

`frontend/tests/guide.mjs`의 캡처 모드에서 별도의 임시 저장소에 합성 테스트 자료만 등록해 촬영했습니다. 운영 DB, 업무 원본, 실제 마감 품번·수량은 사용하지 않았습니다. 이미지 안의 수량과 품번은 설명용입니다.

화면이 바뀌면 프런트엔드를 빌드한 뒤 `CATALYST_CAPTURE_GUIDE=1` 환경 변수로 해당 스크립트를 실행해 다시 촬영합니다. 이미지가 생성된 후 다시 빌드해 배포 파일에 포함합니다. 캡처 모드는 테스트 저장소를 사용하며 기존 프로그램의 저장 경로를 바꾸지 않습니다.
